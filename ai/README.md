# Big Starz AI Pipelines

AI pipeline scripts for the **Big Starz Casting App**, built entirely with free open-source models from [HuggingFace](https://huggingface.co).

---

## Setup

### 1. Install Dependencies

```bash
cd ai
npm install
```

### 2. Get a Free HuggingFace Token

1. Create a free account at [huggingface.co](https://huggingface.co/join)
2. Go to [Settings > Access Tokens](https://huggingface.co/settings/tokens)
3. Generate a new token with `read` scope
4. Copy the token

### 3. Configure Environment

```bash
cp .env.example .env
# Edit .env and paste your HF_API_TOKEN
```

## Available Pipelines

| Pipeline | Script | Description |
|----------|--------|-------------|
| Scene Generator | `npm run generate:scene` | Generates acting scenes with AI-written scripts, dialogue, and imagery |
| Reel Generator | `npm run generate:reel` | Compiles casting reels with TTS narration, subtitles, and transitions |
| Music Video | `npm run generate:video` | Creates AI music videos synced to audio beats |
| Digital Twin | `npm run generate:twin` | Generates a digital twin from reference photos |
| Auto-Enhance | `npm run enhance` | Enhances images/videos with color correction, sharpening, noise reduction |
| Watermark | `npm run watermark` | Adds visible + invisible watermarks to AI-generated content |
| Safety Filter | `npm run safety-check` | Checks text/images for NSFW, hate speech, violence, copyright |
| Auto-Edit | `npm run auto-edit` | Auto-edits video by removing dead air and adding transitions |

## How to Run Each Pipeline

### Scene Generator

```bash
node pipelines/scene-generator.js "A detective interrogates a suspect" thriller "Detective Miller" tense
```

**Output:** `outputs/scenes/scene_<timestamp>_<id>.json` + 3 PNG images

**Fields:**
- `script` — Full scene script
- `dialogue` — Character dialogue
- `stageDirections` — Stage directions
- `imageUrls` — Array of generated scene image paths

---

### Reel Generator

```bash
node pipelines/reel-generator.js "Jane Doe" '["acting","singing","dance"]' '["./clip1.mp4","./clip2.jpg"]' cinematic
```

**Output:** `outputs/reels/reel_<timestamp>_<id>.mp4` + `.srt` subtitles + `.json` metadata

**Features:**
- SpeechT5 voiceover narration
- Whisper-generated subtitles
- Crossfade transitions between clips

---

### Music Video Generator

```bash
node pipelines/music-video.js ./song.mp3 "cyberpunk neon" '["city skyline","flying through clouds","underwater dance"]'
```

**Output:** `outputs/music-videos/music_video_<timestamp>_<id>.mp4`

**Features:**
- Beat-synced keyframe generation
- Image-to-video conversion with Stable Video Diffusion
- Audio-visual synchronization

---

### Digital Twin Generator

```bash
node pipelines/digital-twin.js '["./photo1.jpg","./photo2.jpg"]' "A young actor with dark hair and green eyes"
```

**Output:** `outputs/digital-twins/twin_<timestamp>_<id>_model.json` + multiple PNG variations

**Variations generated:**
- 5 poses × 5 expressions × 5 outfits (sampled subset)
- Consistent likeness via DINOv2 feature extraction + shared seed

---

### Auto-Enhancement

```bash
node pipelines/auto-enhance.js ./photo.jpg '{"sharpen":true,"denoise":true}'
```

**Output:** `outputs/enhanced/enhanced_<timestamp>_<id>.png` (or `.mp4`)

**Options:**
| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `sharpen` | boolean | `true` | Apply unsharp mask |
| `colorCorrect` | boolean | `true` | Adjust brightness/saturation |
| `brightness` | number | `1.05` | Brightness multiplier |
| `saturation` | number | `1.1` | Saturation multiplier |
| `denoise` | boolean | `false` | Apply noise reduction |
| `stabilize` | boolean | `false` | Video stabilization (video only) |

---

### Watermarking

```bash
node pipelines/watermark.js ./generated.png
node pipelines/watermark.js ./video.mp4 "AI Generated by Big Starz"
```

**Output:** `outputs/watermarked/watermarked_<timestamp>_<id>.png` (or `.mp4`)

**Watermarks applied:**
- **Visible:** Bottom-right text overlay with transparency
- **Invisible:** EXIF metadata embedding (`Copyright`, `ImageDescription`, `Artist`)

---

### Safety Filter

```bash
# Text check
node pipelines/safety-filter.js "Text to check" --text

# Image check
node pipelines/safety-filter.js ./image.png --image

# Auto-detect (file extension based)
node pipelines/safety-filter.js ./document.txt
```

**Exit codes:**
- `0` — Content is safe
- `1` — Content flagged or error

**Output format:**
```json
{
  "safe": false,
  "flags": ["nsfw", "violence"],
  "confidence": 0.85,
  "scores": {
    "nsfw": 0.85,
    "hateSpeech": 0.1,
    "violence": 0.75,
    "copyright": 0.0
  }
}
```

---

### Auto-Edit

```bash
node pipelines/auto-edit.js ./raw_footage.mp4 60
```

**Output:** `outputs/enhanced/auto_edited_<timestamp>_<id>.mp4`

**Process:**
1. Detect silence/dead air via FFmpeg `silencedetect`
2. Build keep segments (inverse of silence)
3. Trim to target duration (prioritizes longer segments)
4. Concatenate with fade transitions

## Model References

All models are available via the **HuggingFace Inference API free tier**:

| Task | Model | HuggingFace ID |
|------|-------|----------------|
| Text Generation | Mistral 7B Instruct | `mistralai/Mistral-7B-Instruct-v0.2` |
| Image Generation | Stable Diffusion XL | `stabilityai/stable-diffusion-xl-base-1.0` |
| Image-to-Video | Stable Video Diffusion | `stabilityai/stable-video-diffusion-img2vid-xt` |
| Speech-to-Text | Whisper Large v3 | `openai/whisper-large-v3` |
| Text-to-Speech | SpeechT5 | `microsoft/speecht5_tts` |
| Face Analysis | DINOv2 Large | `facebook/dinov2-large` |
| Text Embedding | all-MiniLM-L6-v2 | `sentence-transformers/all-MiniLM-L6-v2` |

> **Note:** Free tier has rate limits. For production use, consider upgrading to a paid inference endpoint or self-hosting models.
